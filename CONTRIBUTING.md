# Contributing to kritva-standard

Status: DRAFT for Owner approval.

1. Read [GOVERNANCE.md](GOVERNANCE.md) and [AGENTS.md](AGENTS.md).
2. Open a pull request from a branch. Changes to normative text, identifiers, schemas, profile scope or approval policy need explicit Owner review.
3. Write commits in the Kritva commit format with a `Task:` footer from [planning/TASKS.md](planning/TASKS.md).
4. New files use the copyright and SPDX header given in [GOVERNANCE.md](GOVERNANCE.md) section 8.
5. Keep public and private content apart: no private rule text, credentials or infrastructure detail.
6. Contributions are accepted under the repository's Apache License 2.0. A contributor licence agreement process has not been defined for this repository.
